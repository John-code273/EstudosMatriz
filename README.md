# EstudosMatrizes01

## Objetivo

Este projeto tem como objetivo criar um programa em Java que realiza uma pesquisa em uma matriz. O programa deve permitir ao usuário fornecer o número de linhas e colunas da matriz, assim como os valores dos elementos da matriz. Em seguida, o usuário deve informar um número a ser pesquisado na matriz. O programa deve imprimir a posição do número na matriz e, se possível, os valores dos elementos adjacentes (esquerda, cima, direita e baixo).

## Funcionalidades

1. Solicitar ao usuário o número de linhas e colunas da matriz.
2. Solicitar ao usuário os valores dos elementos da matriz.
3. Solicitar ao usuário um número a ser pesquisado na matriz.
4. Procurar o número na matriz.
5. Imprimir a posição do número na matriz.
6. Se o número for encontrado, imprimir os valores dos elementos adjacentes (esquerda, cima, direita e baixo).

## Tecnologias utilizadas

- Java 11

## Como executar

1. Abra o arquivo `EstudosMatrizes01.iml` no Intellij IDEA.
2. Clique no botão "Run" na barra de ferramentas para executar o programa.
